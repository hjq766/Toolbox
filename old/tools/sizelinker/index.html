功能介绍

长宽联动工具帮助您根据已知的原始尺寸，快速计算出按比例缩放后的目标尺寸，保持宽高比例不变。

提示：在已知原始宽高后，输入任意一个目标值（宽或高），另一个会自动计算。原始尺寸中的宽或高为 0 或空时将无法联动。

使用方法

  • 输入原始尺寸：在左侧卡片中输入已知的宽度和高度
  • 计算目标尺寸：在右侧卡片中输入新的宽度或高度
  • 自动计算：另一个值会自动按比例计算出来

实用功能

  • 比例显示：实时显示当前的宽高比例
  • 交换宽高：一键交换目标尺寸的宽高值
  • 复制尺寸：将计算结果复制到剪贴板
  • 一键重置：清空所有输入重新开始

适用场景

  • 图片缩放：保持原始比例调整图片大小
  • 设计稿适配：计算不同屏幕尺寸下的元素大小
  • 视频分辨率：计算不同分辨率下的视频尺寸
  • 打印输出：计算打印时的实际尺寸
