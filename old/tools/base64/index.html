功能简介

Base64 编码转换工具支持文本和图片的 Base64 编码转换，可以快速进行编码、解码和预览。

主要功能

  • 文本编码 - 支持文本内容的 Base64 编码与解码
  • 图片编码 - 支持图片转 Base64 编码，可直接用于 CSS 或 HTML
  • 实时预览 - 支持 Base64 编码图片的实时预览
  • 字符集选择 - 支持 UTF-8 和 GBK 字符集
  • URL-safe 模式 - 支持 URL 安全的 Base64 编码
  • 换行格式 - 支持标准的 76 字符换行格式

使用说明

  • 在输入框中输入需要处理的文本，点击"编码"或"解码"按钮
  • 使用"一键转换"可自动识别输入内容是原文还是 Base64 编码
  • 图片模式下，上传图片后会自动生成 Base64 编码
  • 可以直接粘贴 Base64 编码到输出框，点击"还原预览"查看图片

注意事项

  • Base64 编码后的文本会比原文长约 33%
  • 大图片转 Base64 会生成很长的字符串，建议小于 1MB
  • URL-safe 模式会将 + 替换为 -，/ 替换为 _
