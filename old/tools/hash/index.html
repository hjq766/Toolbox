功能说明

哈希计算工具支持多种哈希算法，可以计算文本和文件的哈希值，所有计算均在本地完成，保证数据安全。

主要功能

  • 文本哈希 - 支持文本内容的多种哈希算法计算
  • 文件哈希 - 支持单个或批量文件的哈希值计算
  • HMAC 支持 - 文本模式支持 HMAC 密钥哈希
  • 多算法 - 支持 MD5、SHA1、SHA256、SHA512 等算法
  • 一键复制 - 每个哈希结果都可独立复制

使用说明

  • 文本模式：输入文本，选择算法，点击计算即可
  • HMAC 模式：勾选"使用 HMAC"并输入密钥
  • 文件模式：上传文件后自动计算选中的哈希算法
  • 支持批量文件处理，可同时计算多个文件

注意事项

  • 所有计算均在本地浏览器完成，不会上传到服务器
  • 大文件计算可能需要较长时间，请耐心等待
  • MD5 和 SHA1 已不推荐用于安全场景，建议使用 SHA256 或更高
