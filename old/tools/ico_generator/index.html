功能介绍

主要功能

  • 支持生成Windows ICO、macOS ICNS、iOS和Android应用图标
  • 专业的网站Favicon生成，支持多种尺寸
  • 智能图片裁剪，支持自定义裁剪区域
  • 圆角设置，内置iOS标准圆角值（22.37%）
  • 按平台规范生成对应倍数的图标资源
  • 支持PNG、JPG、WebP等格式转换
  • 支持单个下载和批量打包下载
  • 所有处理在浏览器中完成，保护隐私安全

平台规范

  • Windows ICO：16×16到512×512多种尺寸，适用于桌面应用
  • macOS ICNS：256×256到1024×1024，支持Retina显示
  • iOS应用图标：20×20到1024×1024，包含@2x和@3x倍数
  • Android应用图标：48×48到512×512，包含各种DPI密度
  • 网站Favicon：16×16到256×256，兼容各种浏览器

使用说明

  • 上传图片：拖拽或点击上传，建议使用1024×1024以上的高清图片
  • 选择平台：根据需要选择Windows、macOS、iOS、Android或Favicon
  • 设置圆角：iOS应用建议使用22.37%的标准圆角
  • 裁剪图片：如需要可使用裁剪工具调整图片区域
  • 选择尺寸：使用快速选择或手动选择需要的图标尺寸
  • 生成下载：点击生成后可单独下载或批量打包下载

专业提示

  • iOS图标：系统会自动添加圆角，建议使用22.37%圆角预览效果
  • Android图标：支持自适应图标，建议图案居中且留有边距
  • Favicon：小尺寸图标建议使用简单图案，避免复杂细节
  • 高清显示：上传高分辨率图片确保在各种设备上显示清晰
  • 颜色模式：建议使用RGB颜色模式，避免CMYK模式
