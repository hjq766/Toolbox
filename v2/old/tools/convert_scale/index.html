功能介绍

宽高比换算工具可以帮助您快速计算和调整图像、视频或设计稿的宽高比例，方便进行尺寸转换和比例调整。

主要功能

  • 支持输入任意宽高值，自动计算比例
  • 提供常用比例预设（16:9、4:3、3:2、1:1等）
  • 实时显示简化比例和宽高比值
  • 可视化预览当前比例效果

使用说明

  • 输入宽度或高度，另一值会自动按比例计算
  • 点击常用比例按钮，快速切换到预设比例
  • 使用快捷操作按钮：交换、复制、重置
  • 右侧实时预览当前比例的可视化效果

快捷键

  • Ctrl/Cmd + S - 交换宽高
  • Ctrl/Cmd + C - 复制尺寸（焦点在输入框时）
  • Ctrl/Cmd + D - 重置为默认尺寸

使用场景

  • 设计师调整图片或设计稿尺寸
  • 视频制作时计算不同分辨率
  • 开发人员计算屏幕适配比例
  • 摄影爱好者进行照片裁剪
