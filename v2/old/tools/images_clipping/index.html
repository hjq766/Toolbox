功能介绍

专业的在线图片裁剪工具，支持自由裁剪和多种固定比例裁剪。提供旋转、翻转等编辑功能，所有操作在浏览器本地完成，保护您的隐私安全。

核心功能

  • 自由裁剪 - 支持任意尺寸的自由裁剪，拖动裁剪框调整大小和位置
  • 固定比例 - 提供1:1、4:3、16:9等常用比例，适合社交媒体和各种场景
  • 旋转翻转 - 支持90度旋转和水平/垂直翻转，快速调整图片方向
  • 实时预览 - 裁剪框内实时显示裁剪效果，所见即所得
  • 保持原格式 - 自动保持原始图片格式输出，无损裁剪
  • 精确控制 - 实时显示裁剪区域和原始尺寸，精确到像素

使用方法

  • 上传图片 - 点击或拖拽图片到上传区域，也可使用 Ctrl+V 粘贴剪贴板图片
  • 调整裁剪框 - 拖动裁剪框移动位置，拖动边角调整大小
  • 选择比例 - 点击右侧比例按钮切换裁剪比例，或选择自由裁剪
  • 旋转翻转 - 使用工具栏按钮旋转或翻转图片
  • 开始裁剪 - 点击"开始裁剪"按钮生成裁剪结果
  • 下载保存 - 预览裁剪结果后点击下载，或继续调整裁剪

特色亮点

  • 拖拽调整 - 裁剪框支持8个控制点，可从任意方向调整大小
  • 比例锁定 - 选择固定比例后，裁剪框自动保持比例不变
  • 快捷键支持 - 支持键盘快捷键操作，提升效率
  • 粘贴上传 - 支持从剪贴板直接粘贴图片，方便快捷
  • 格式保持 - 自动识别并保持原始图片格式，无需手动选择
  • 本地处理 - 所有操作在浏览器本地完成，保护隐私

技术说明

  • 使用HTML5 Canvas技术进行图片处理，兼容性好
  • 支持高分辨率图片处理，保持原始图片质量
  • 自动识别图片格式（PNG/JPEG/WebP等），输出相同格式
  • PNG格式保留透明通道，确保图片效果不变
  • 所有处理均在浏览器本地完成，图片不会上传到服务器

快捷键

  • Ctrl + V - 粘贴图片
  • Enter - 确认裁剪
  • Esc - 取消/重置
  • Delete - 删除图片
